Cloud-1 is a cloud infrastructure project for hosting WordPress on AWS.
 Ansible automates server configuration and deployment, while Docker Compose manages the containerized application stack: Nginx, WordPress, MariaDB, and phpMyAdmin. Persistent volumes store website files and database data.
